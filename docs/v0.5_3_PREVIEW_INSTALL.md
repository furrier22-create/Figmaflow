## 2. Használat

1. Nyisd meg a Motion Studio-t (`Tools → FigmaFlow → Motion Studio`)
2. Állítsd be: **From** / **To** (a két VTA) + **Transition Asset** + **Profile**
3. **"Load Preview"** gomb → megnyílik a **FigmaFlow Preview** ablak; a logban: `[FigmaFlow] Preview kész: N track, X.XXs`
4. A **Preview ablakban**: **"Play"** gomb → az átmenet lejátszódik (a vizuális fa az ablakban); a **slider** húzásával bármikor belenézhetsz egy időpontba; **"Stop"** megállítja
5. A slider húzása → `Seek` (az adott időpillanat értékelése)

## 3. Elvárt viselkedés

- A lejátszás a **FigmaFlow Preview ablakban** látszik (tiszta UI Toolkit — a Motion Studio IMGUI-s, ott a UI Toolkit nem renderelődne)
- A **jelenet UIDocument-je nem bántva** (a preview a saját ablakában fut)
- A lejátszás a meglévő, bizonyított pipeline-t használja (Analyze → Build → Evaluate) — **a Motion Engine érintetlen**
- Az editor-only layout a **frame-várakozás mintával** érvényesül (a resolvedStyle késleltetett — ugyanaz, mint a runtime-ban)
- **Scale-to-fit (2026-08-02):** a desktop a **természetes képarányában**, determinisztikusan középre igazítva (kézi pozíció-számítás, bal-felső origó, abszolút konténer). **Ha a két állapot desktopja MÁS méretű** (pl. tab menü: from 1019×487 → to 1019×244), a végállapot (`ShowFinalState`) **reseteli a méretet és újrailleszti** a to desktopot — különben a végállapot a from-méretre skálázva elcsúszna.
- **Végállapot (2026-08-02):** a lejátszás végén a **to fa** betöltődik (a háttér/szín is a végleges); a Play újra a from-ról indul
- **Slider (2026-08-02):** a húzás a `Seek`-et hívja, az Update nem írja felül húzás közben; a **végállapotból a húzás visszatölti a from fát** (a régi transition a leválasztott elemekre mutatna) és alkalmazza a seek-elt időt; a slider **végén a végállapot (to fa)** jelenik meg (a háttérszín váltás is látszik)

**Ismert limitáció:** a **színváltozás** (pl. aktív tab színe) az animáció alatt ugrik (a Motion Engine csak Position/Size/Opacity-t animál — nincs ColorTrack, az `ElementTrack` freeze). A végállapot (to fa) helyes színt mutat; a szín-animáció egy jövőbeli freeze-feloldással jöhet.

## 4. Teszt menet

1. Másold be a 2 fájlt → fordíts (hiba nélkül)
2. Motion Studio → állítsd be a Dialog demo from/to + asset + profilt
3. **Load Preview** → a log: `Preview kész: N track`
4. **Play** → az átmenet lejátszódik (a rejtett dokumentumban — a Motion Studio ablakban a slider mozog)
5. **Slider húzás** → az időpontra ugrik
6. **Regresszió:** a runtime (Play Mode) demók változatlanok — a preview csak editor

## 5. Hogyan működik (technikailag — ADR-019)

- `TransitionPreview`: a from fa az élő alap (a preview azon animál); a to állapot capture egy ideiglenes betöltéssel; az elemzés + építés a `ScheduleOnce`-szal (a layout lefutása után)
- Az `EditorWindow.Update` hajtja a lejátszást (`EditorApplication.timeSinceStartup` delta)
- A `Seek` a `transition.Evaluate(time)`-t hívja — ugyanaz, mint a runtime player

## 6. Ha valami nem működik

- **A desktop nem illeszkedik / a két állapot desktopja eltérő méretű** → **a UXML-ben a gyökér (Desktop) eleme fix méretű legyen (pl. 1920×1080)** — az `auto` méret a tartalomhoz igazodik (a tab menünél 1019×487 → 1019×244 volt, ami miatt a végállapot elcsúszott). A Figma-importok eleve 1920×1080-as vászonról jönnek; a kézzel készített UI Toolkit demóknál (Unity UI Builder) ezt állítsd be. A preview a fix desktopot illeszti az ablakba; a különböző méretű állapotoknál a végállapot-reset újrailleszt.
- **Nincs `Preview kész` log** → a Load gomb előtt a from/to/asset/profile beállítva? (a gomb inaktív, ha nem)
- **A preview nem animál (csak ugrik)** → a StateCache-elavultság itt is okozhatja; a from/to VTA-k a jelenetben használtak legyenek
- **A lejátszás "szaggat"** → az editor Update frame-függő; a slider húzása (Seek) pontosabb
- **A Preview ablakban csak a Play gomb + slider látszik, semmi sem történik** → **2026-08-02 hotfix:** (1) a vezérlők és a tartalom KÜLÖN gyermeken van (a `Load` csak a tartalmat törli — a `root.Clear()` korábban a vezérlőket is törölte), (2) a `Reload` a `EditorApplication.delayCall`-lal fut (a `CreateGUI` a `GetWindow` után késleltetve érkezhet, amikor a `pending*` még null — a Load soha nem indult). **A `FigmaFlowPreviewWindow.cs` frissített verzióját másold be.**
- **Fordítási hiba / NRE / "not my child"** → a `TransitionPreview.cs` + `FigmaFlowPreviewWindow.cs` + `FigmaFlowWindow.cs` EGYÜTT cserélendő; a preview a saját, UI Toolkit-alapú ablakban fut (a Motion Studio IMGUI-s — ott a UI Toolkit nem renderelődne). A "not my child" hibát a **load-token** + `RemoveFromHierarchy` oldja (a többszöri Load Preview-nál a régi függőben lévő build nem folytatódik)
