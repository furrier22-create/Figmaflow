# v0.5/7 — Per-Pair TransitionAsset: telepítés és teszt

> Páronként (state-páronként) eltérő átmenet-stílus — minden párnak saját
> `TransitionAsset`-je (más delay/duration/ease/appearMode). A runtime és a
> szekvencia-preview a pár szerint választ; a default a fallback.

---

| `Assets/FigmaRuntime/Runtime/FigmaStateMachine.cs` | `Runtime/` | **CSERE** — `pairAssets` + `ResolveAsset` + a PlayTransition pár-választása |

## 2. Munkafolyamat

1. **Minden párhoz külön asset:** a Motion Studio-ban állítsd be a pár **From/To** desktopjait → **Generate** → létrejön a `{from}_{to}.asset` (a fájl neve már pár-specifikus)
2. **A pár assetjét add a géphez:** a State Machine mezőre húzd a gépet → **"Add Current Pair to StateMachine"** gomb → az asset bekerül a `pairAssets` tömbbe (a log: `Pair asset hozzáadva: {from} -> {to}`)
3. **Szerkeszd páronként:** a Timeline-ban/Preview-ban a pár assetjét választva állítsd be a delay/duration/ease/appearMode-ot — minden pár más lehet (pl. 0→1: 0.4s EaseInOut fade; 1→2: 0.8s SlideUp)
4. **Runtime:** a `GoToState(i)` a pár szerint választ — a 0→1 az egyik, az 1→2 a másik assetet használja

## 3. Elvárt viselkedés

- **Pár-specifikus:** a 0→1 és az 1→2 átmenet **eltérő stílusú** lehet (más duration/ease/appear)
- **Fallback:** ha egy párra nincs asset a `pairAssets`-ben → a default `transitionAsset`
- **Szekvencia-preview:** a teljes 0→1→2→… **páronként a saját assetjével** játszódik (a gép átadásával)

## 4. Teszt menet

1. Másold be a 4 fájlt → fordíts
2. A tab menühöz (3 állapot): generálj **0→1** és **1→2** assetet (külön-külön, a From/To átállításával)
3. Az **Add Current Pair** gombbal add mindkettőt a gép `pairAssets` tömbjéhez
4. A Motion Studio-ban a két assetnek **más beállítást** adj (pl. az egyik 0.4s EaseInOut, a másik 0.8s SlideUp)
5. Play Mode → a 0→1 és az 1→2 **eltérően animálódik**
6. **Regresszió:** a `pairAssets` üresen hagyott gépek (Shoes, Dialog…) → a default `transitionAsset` működik (változatlan)

## 5. Megjegyzések

- A `ResolveAsset` a **nevek** alapján párosít (`fromState`/`toState` a `TransitionAsset`-ben) — a Generate eleve ezt írja a fájlba
- A `transitionAsset` mező továbbra is a fallback — a `pairAssets` csak a pár-specifikus felülírás
- A PlayMaker és a navigáció a `GoToState`-on megy — a pár-választás automatikus, semmi extra beállítás
- A Motion Engine-hez nem nyúltunk (a `Build` ugyanaz — csak más assetet kap)
