## 2. SlotPuzzle — beállítás

1. A UXML-ben: a **tárgyak** (a `solutionOrder` névvel) és a **slotok** (a `slotNames` névvel) — pl. 3 tárgy + 3 slot
2. A GameObject-en: **`SlotPuzzle`** komponens + `document` (a UIDocument) + `solutionOrder` (a helyes sorrend) + `slotNames` + `solvedState` (+ a `machine`)
3. **Működés:** egy tárgy érintése → kiválasztás (a `selectedClass` kiemelés); egy slot érintése → a tárgy odakerül; a helyes sorrend → `GoToState(solvedState)` + `onSolved`
4. **Visszavétel:** üres kézzel egy foglalt slot érintése → a tárgy vissza a "kézbe"

## 3. CombinationLock — beállítás

1. A UXML-ben: a **tárcsák** (a `dialNames` névvel) + mindegyikhez egy **érték-label** (`dialName + "_value"`)
2. A GameObject-en: **`CombinationLock`** + `document` + `dialNames` + `solution` (a helyes kombináció) + `solvedState` (+ `machine`)
3. **Működés:** egy tárcsa érintése → a következő értékre fordul (a label frissül); `autoCheck` (minden lépésnél) vagy `checkButtonName` (Check gomb); a helyes kombináció → `GoToState(solvedState)` + `onSolved`

## 4. Teszt menet

1. Másold be a 2 fájlt → fordíts
2. **SlotPuzzle:** Play Mode → egérrel: tárgy → slot → tárgy → slot → ... → a helyes sorrend → a `solvedState` megnyílik; rossz sorrend → `onWrong` (+ visszaállítás)
3. **CombinationLock:** tárcsák → a helyes kombináció → a `solvedState` megnyílik; rossz → `onWrong`
4. **Regresszió:** a TUIO-input (a ClickEvent-ek a puzzle-oknak is mennek), a runtime demók → változatlan

## 5. Megjegyzések

- **BIND-IDŐZÍTÉS (2026-08-02):** a puzzle-ok a fa betöltésére várnak (a `TryBind` az `Update`-ben próbálkozik, amíg minden elem megvan) — a `StateMachine.Start` aszinkron tölti a fát, az `OnEnable`-kori bind üres fát találna (a tünet: `bind kész — slotok 0/2`). Ha a név rossz, a `bind próba N` log jelzi (60 próba után megáll).
- A puzzle-ok a **ClickEvent-eket** figyelik — a TUIO-input a mapping nélküli érintéseket ClickEventté alakítja, tehát a puzzle a **TUIO-val és az egérrel is** működik
- A **Figma state-ek** (a `solvedState` + a "zárva" állapot) csak a vizuális visszajelzés — a kombinációk a logikában élnek
- A **PuzzleFeedback** (hiba-rázkódás, kiválasztás-kiemelés) a következő lépés — most a `selectedClass` (CSS) adja a kiemelést, az `onWrong` az eseményt
- A **Motion Engine-hez nem nyúltunk** (freeze)
