# v0.5 — Rotation támogatás (ADR-023): telepítés és teszt

> A UI Builder / Figma rotate értékének animálása (F8 zárás). A PNG+rotate
> út (a Figma-import hiányosságai miatt) mostantól teljes: az elforgatott
> elemek a két állapot között ELFORGÁSSAL animálódnak, nem ugrással.

---

## 1. Fájlok — mit másolj hova

| Fájl (workspace) | Cél (projekt) | Típus |
|---|---|---|
| `Assets/FigmaRuntime/Runtime/StateCapture.cs` | `Runtime/` | **CSERE** — a `resolvedStyle.rotate.angle` rögzítése |
| `Assets/FigmaRuntime/Core/AnimatedProperties.cs` | `Core/` | **CSERE** — + `Rotation = 8` flag |
| `Assets/FigmaRuntime/Core/TransitionBuilder.cs` | `Core/` | **CSERE** — rotation-detektálás (0.5° tolerancia) |

## 2. Elvárt viselkedés

- A **PNG-elemek** (UI Builder rotate-tal): a két állapot között az elforgatás **animálódik** (pl. egy ikon 0° → 45° között forog), nem ugrik
- A meglévő animációk (Position/Size/Opacity) **változatlanok**

## 3. Teszt menet

1. Másold be az 5 fájlt → fordíts
2. A **PNG+rotate demód** (a desktop 2): Play Mode → a váltásnál az elforgatott elem **szépen forog** a két állapot között
3. A **StateCache-et exportáld újra** (a rotation adatok a capture-ben frissüljenek!)
4. **Regresszió:** a tab menü, cipős, Dialog/BottomSheet/Popup, Hero → változatlan (a rotation-tolerancia 0.5° — a nem forgó elemek nem kapnak rotation-tracket)

## 4. Megjegyzések

- A **scale továbbra is 1-re rögzített** a capture-ben (a ScaleTrack külön feladat — a jövőbeni F8-rész, ha kell)
- A rotation a **`style.rotate`**-ot animálja (a PositionTrack translate-módjával kompatibilis — mindkettő transzformáció)
- A freeze-eszkaláció dokumentálva az `ElementTrack` fejlécében és az ADR-023-ban (a meglévő három track érintetlen)
