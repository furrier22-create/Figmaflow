## 3. Használati folyamat (egyszer, majd automatikus)

**1. lépés — első futtatás (egyszeri):**
- Lépj Play Mode-ba. Még nincs cache → a régi fallback fut (runtime capture, a workaround-dal). Ez normális, ez az a futtatás, ami a cache-t "megcsinálja".

**2. lépés — export:**
- Motion Studio (`Tools → FigmaFlow → Motion Studio`)
- Az új **State Cache** szekcióban: **Export State Cache** gomb
- Az asset létrejön: `Assets/FigmaFlow/Cache/StateCache_<jelenetneve>.asset` (a log jelzi)

**3. lépés — beállítás:**
- Lépj ki Play Mode-ból
- Húzd a létrejött assetet a `FigmaStateMachine` **State Cache** mezőjére
  (vagy a Motion Studio mezőjéből válaszd ki — ugyanaz a mező)

**4. lépés — eredmény:**
- Lépj újra Play Mode-ba. A logban:
  `[FigmaFlow] StateCache betöltve: N state (nincs runtime capture — nincs felvillanás).`
- **Nincs felvillanás**, a HideRoot workaround nem fut.

## 4. Ellenőrző lista

## 5. Visszaállás / hibakezelés

| Helyzet | Megoldás |
|---|---|
| Cache-t törlöd / nem állítod be | A mező üres → a runtime capture fallback fut (a v0.3.7 viselkedés) — semmi nem törik |
| "A StateCache (N) nem egyezik a states tömb méretével (M)" | Változtak a VTA-k a cache óta → **újra kell exportálni** (2. lépés) |
| A VTA-k tartalma változott (ugyanannyi darab) | A régi cache elavult adatot ad → **újra kell exportálni** |
| Export gomb: "Play Mode-ban működik" | Még nincs Play Mode-ban — az export valódi layoutot igényel |

## 6. Mi lett új a `FigmaStateMachine`-ben (ha kézzel illeszted)

1. Mező: `public FigmaStateCacheAsset stateCache;` (a `transitionAsset` után, "State Cache (v0.4)" fejléc alatt)
2. `Start()` elejére a cache-ág: `if (TryLoadStateCache()) { host.Load(states[0]); currentState = 0; yield break; }` — a fallback (HideRoot + capture ciklus) utána marad
3. Új metódusok: `TryLoadStateCache()` (darabszám-ellenőrzés + CachedState → FigmaStateAsset konverzió) és `GetCapturedStates()` (az export eszköznek)
