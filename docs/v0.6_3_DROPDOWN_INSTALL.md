# v0.6/3 — Dropdown + popup scale-in: telepítés és teszt

> A lenyíló menü (Dropdown) + az `AppearMode.Scale` — a megjelenő elem
> kicsinyről a teljes méretére nő (a popup/dropdown "megnőve" megjelenés).

## 1. Fájlok — mit másolj hova

| Fájl (workspace) | Cél (projekt) | Típus |
|---|---|---|
| `Assets/FigmaRuntime/Data/FigmaFlowProfile.cs` | `Data/` | **CSERE** — + `AppearMode.Scale` |
| `Assets/FigmaRuntime/Core/TransitionBuilder.cs` | `Core/` | **CSERE** — a Scale ág + `CreateScaledCopy` |
| `Assets/FigmaRuntime/Samples/DropdownDemo/` (3 fájl) | `Samples/DropdownDemo/` | **ÚJ** — a dropdown demo |

## 2. Beállítás (új GameObject, pl. `DropdownDemo`)

1. `UIDocument` (Source Asset = NONE) + `FigmaDocumentHost` + `FigmaStateMachine` (states: [Dropdown_Closed, Dropdown_Open]) + `TransitionPlayer` + `OverlayRuntime` + `OverlayScene` + `OverlayTransitionPlayer` + `DropdownDemoInput` (machine → a StateMachine)
2. Profil: `animationMode = Overlay`
3. **TransitionAsset:** Play Mode → Next → Motion Studio → Generate → az asset a `transitionAsset` mezőre
4. **A `DropdownMenu` item Appear beállítása = `Scale`** (a Motion Studio-ban) — a menü kicsinyről nő; a többi item maradhat Fade

## 3. Elvárt viselkedés

- **Nyitás** (a "Válassz opciót" gomb): a `DropdownMenu` **kicsinyről a teljes méretére nő** (scale-in, nem csak fade) — a log: `[FigmaFlow] Scale appear: DropdownMenu`
- **Opció kiválasztása** (Piros/Zöld/Kék) → bezárás + a `Selection` labelbe: `Kiválasztva: Piros` stb.
- **Kattintás a háttérre** (a menün kívül) → bezárás (click-away)
- **A gomb toggle:** nyitva állapotban rákattintva bezár
- **Barrier:** a menün belüli kattintás (a gombokon kívül) nem zár
- A bezáráskor a menü **visszazsugorodik** (scale-out) — a log: `Scale disappear`

## 4. Teszt menet

1. Másold be a 2 kód-fájlt + a 3 demó-fájlt → fordíts
2. Play Mode → nyitás → a menü **megnő** (nem ugrik)
3. Válassz egy opciót → a label megjeleníti, a menü visszazsugorodik
4. Nyitás → kattintás a háttérre → bezár
5. **Regresszió:** a Dialog/BottomSheet/Popup/Hero (Fade/SlideUp) → változatlan; a Motion Studio "Appear" választója már mutatja a Scale-t

## 5. Megjegyzések

- A Scale a **Size + Opacity** property-ket használ (a meglévő SizeTrack + OpacityTrack) — **nincs új track, a Motion Engine érintetlen**
- A skála **középpontból** történik (a `CreateScaledCopy` a worldRect középpontja körül kicsinyít) — a növekedés középre fut
- A Dropdown a Popup sablon 4. alkalmazása — a pipeline továbbra is új engine-funkció nélkül bővíthető
