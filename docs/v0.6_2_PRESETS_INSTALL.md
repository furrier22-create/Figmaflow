# v0.6/2 — Motion Presets: telepítés és teszt

> A gyakori mozgás-beállítások (ease/duration/appearMode) mentése és
> egy gombbal az összes itemre alkalmazása (ADR-027).

---

## 1. Fájlok — mit másolj hova

| Fájl (workspace) | Cél (projekt) | Típus |
|---|---|---|
| `Assets/FigmaRuntime/Data/MotionPreset.cs` | `Data/` | **ÚJ** — a preset adat |
| `Assets/FigmaRuntime/Data/TransitionAsset.cs` | `Data/` | **CSERE** — + `presets` lista |
| `Assets/FigmaRuntime/Editor/FigmaFlowWindow.cs` | `Editor/` | **CSERE** — a Presets szekció |

## 2. Használat (a Motion Studio-ban)

1. A **Motion Presets (v0.6)** szekcióban: add meg a **Preset név**-et, az **Ease**-t, a **Duration**-t, az **Appear**-t
2. **"Mentés presetként"** → a preset bekerül a transitionAsset `presets` listájába (a log: `Preset mentve: 'Név'`)
3. A mentett presetek a listában: `Név (Ease, 0.60s, AppearMode)`
4. **"Apply to All Items"** → a kiválasztott preset (ease/duration/appear) az **összes itemre** (a log: `Preset 'Név' alkalmazva N itemre`)
5. **"Preset törlése"** → a kiválasztott preset törlése

## 3. Elvárt viselkedés

- A presets az **assetben tárolódik** — a pár-asseteknek (per-pair) saját preset-készletük lehet
- A Timeline/Preview-ban a változás látszik (a preset alkalmazása után a Load Preview újratöltésével)
- Az Apply az `ease` + `duration` + `appearMode`-ot állítja (a delay és a properties érintetlen)

## 4. Teszt menet

1. Másold be a 3 fájlt → fordíts
2. Motion Studio → Presets → ments egy "Gyors fade" presetet (Linear, 0.3s, Fade)
3. **Apply to All Items** → a Timeline-ban/Preview-ban minden item 0.3s Linear Fade
4. Ments egy "Csúszó" presetet (EaseOut, 0.8s, SlideUp) → alkalmazd → a slide-ok lassulnak
5. **Regresszió:** a Timeline-húzás, a Preview, a runtime → változatlan

## 5. Megjegyzések

- A preset **nem tartalmazza a delay-t és a customCurve-ot** (az item-specifikus marad) — ha kell, később bővíthető
- A preset-alkalmazás **felülírja** az itemek beállításait (visszavonás nélkül) — a Timeline-ban ellenőrizhető
