# v0.5/4 — States Sequence Preview: telepítés és teszt

> A Motion Studio mostantól a **StateMachine `states` tömbjéből** is tud
> előnézetet indítani — a teljes **0→1→2→… szekvencia** automatikusan,
> páronként lejátszva (a gép `transitionAsset`-jével — path-alapú, így
> minden párra működik). Ez a Timeline (v0.5/5) alapja.

## 2. Használat

1. Nyisd meg a Motion Studio-t → **States Sequence (v0.5)** szekció
2. **State Machine** mező → húzd be a jelenet `FigmaStateMachine`-jét (amelyiknek a `states` tömbje a szekvenciát adja)
3. **Load Sequence Preview** gomb → megnyílik a Preview ablak a szekvencia-módban
4. **Play** → a 0→1 átmenet lejátszódik, majd **automatikusan** a 1→2, stb. — az utolsó pár után a végállapot
5. A **slider** az aktuális páron belül húzható; az info: `Pár 1/2`
6. **Play a végállapotból** → a **teljes szekvencia újraindul** (a 0. párról)

## 3. Elvárt viselkedés (tab menü, 3 állapot)

- `[FigmaFlow] Szekvencia betöltve: 3 állapot (2 átmenet).`
- Play → 0→1 (a tab váltás) → 1→2 (a következő tab) → a végállapot (a 2. tab aktív)
- Az info: `Pár 1/2` → `Pár 2/2` (az átmenetek között)
- A Play újra → a teljes 0→1→2 végig

## 4. Regresszió

- **Egyes mód (Load Preview, from/to)** → változatlanul működik (a `Load` törli a szekvencia-módot — a két mód független)
- Shoes / tab menü runtime (Play Mode) → változatlan

## 5. Technikai megjegyzés (ADR-020)

- A szekvencia a gép **egyetlen `transitionAsset`-jét** használja minden párra (a `Build` path-alapú lookup — a pár-specifikus from/to a `Analyze`-ből jön, az item-beállítások (delay/duration/ease/appear) közösek). A per-pár asset-ek (minden átmenethez külön) egy későbbi finomítás — a Timeline-lal együtt.
- Az auto-advance a `ShowFinalState`-ban történik (a pár lejátszása után a következő pár betöltése); a `sequenceMode`-ot a `Load` törli, az auto-advance visszaállítja.
