## 2. TUIO-integráció (v0.6/1)

**A folyamat:**
```
TUIO küldő (érintőfal)
   ↓ UDP 3333 (TuioNet/TuioUnity — a meglévő asset)
TuioSessionBehaviour
   ↓ cursor események (Position: normalizált 0..1, Y felfelé)
FigmaFlowTuioInput  (implements IFigmaFlowInput)
   ├─ érintés → panel-pozíció (flipY)
   ├─ root.panel.Pick(pos) → a VisualElement a pont alatt
   ├─ MAPPING: elementName → stateIndex (GoToState) — Inspectorban
   └─ mapping nélkül → szintetikus ClickEvent (a meglévő kezelők élnek)
   └─ Activate() → a PlayMaker idle-reset
```

**Egér-tesztelés:** a `simulateWithMouse` kapcsoló — bal klikk ugyanazon a pipeline-on (Pick + mapping + click). A mapping így egérrel beállítható és tesztelhető, valódi érintőfal nélkül.

**Beállítás (scene):**
1. A `TuioSessionBehaviour` a jelenetben (az IP/UDP port a te hálózatodnak)
2. A `FigmaFlowTuioInput` a `UIDocument`-es GameObject-en: `tuioSession` → a TuioSessionBehaviour; `machine` → a StateMachine
3. **Mapping:** a listába add az elem nevét (a UXML-ből) + a cél state indexet
4. Play Mode → egérrel teszteld (bal klikk az elemre), majd az érintőfalról élesben
