# v0.6/5 — Editor-only StateCache: telepítés és teszt

> A StateCache export mostantól **Play Mode nélkül**, tisztán editorban is
> elkészíthető — az offscreen méréssel (ADR-029). A runtime betöltése
> változatlan.

---

## 1. Fájlok — mit másolj hova

| Fájl (workspace) | Cél (projekt) | Típus |
|---|---|---|
| `Assets/FigmaRuntime/Editor/StateCacheExporter.cs` | `Editor/` | **CSERE** — + `ExportOffscreen` + `FinishOffscreenExport` |
| `Assets/FigmaRuntime/Editor/FigmaFlowWindow.cs` | `Editor/` | **CSERE** — "Export State Cache (Editor)" gomb |

## 2. Használat

1. Motion Studio → **State Cache** szekció → a **State Machine** mezőre húzd a gépet
2. **"Export State Cache (Editor)"** gomb → az export **edit módban, Play Mode nélkül** fut:
   - a `states` tömb minden VTA-ját egy rejtett UIDocument-re tölti (1920×1080)
   - sorban capture-öli (a `schedule` + frame-várakozás mintával)
   - létrehozza a `StateCache_{gép}.asset`-et a scene almappába
   - a log: `[FigmaFlow] Offscreen StateCache exportálva: N state -> ... (scene: ..., Play Mode NÉLKÜL).`
3. Az asset kiválasztódik → **húzd a StateMachine `stateCache` mezőjére**
4. Play Mode → a runtime a cache-ből tölt (nincs felvillanás, nincs runtime capture)

## 3. Elvárt viselkedés

- Az export **edit módban** is működik (nem kell Play Mode!)
- A létrehozott asset **ugyanaz a formátum** (a meglévő `FigmaStateCacheAsset`) — a runtime változatlan
- A Play Mode-os "Export State Cache" gomb **megmarad** (opció — pl. ha a scene-kontextus kell)

## 4. Teszt menet

1. Másold be a 2 fájlt → fordíts
2. **Edit módban** (Play Mode nélkül): Motion Studio → State Machine → **Export State Cache (Editor)**
3. A log: `Offscreen StateCache exportálva: N state`
4. Az assetet a `stateCache` mezőre → Play Mode → `StateCache betöltve: N state` (a régi módon)
5. **Regresszió:** a Play Mode-os export továbbra is működik; a runtime demók változatlanok

## 5. Megjegyzések

- **Ismert korlát:** ha egy VTA scene-kontextustól függ (pl. bindings), az offscreen nem azt adja, mint a futó scene — a Figma-exportok (statikus) esetén nem gond
- A rejtett host (`HideAndDontSave`) automatikusan törlődik az export végén
- A `panelSettings` a hoston (`CreateInstance<PanelSettings>`) — nélküle a rootVisualElement nem jönne létre
