## 2. Beállítás (új GameObject, pl. `HeroDemo`)

1. `UIDocument` (Source Asset = NONE) + `FigmaDocumentHost` + `FigmaStateMachine` (states: [HeroDemo_Closed, HeroDemo_Open]) + `TransitionPlayer` + `OverlayRuntime` + `OverlayScene` + `OverlayTransitionPlayer` + `HeroDemoInput` (machine → a StateMachine)
2. **Profil — KÉT dolog:**
   - `animationMode` = **Overlay**
   - **`useAnimationLayer` = TRUE** ← ez az első demo, ahol a layer BE van kapcsolva!
3. **TransitionAsset:** Play Mode → Next → Motion Studio → Generate → az asset a `transitionAsset` mezőre
4. **StateCache:** exportáld újra ehhez a scene-hez (a kártya pozíciói a capture-ből jönnek)

## 3. Elvárt viselkedés

- **Megnyitás** (kattintás a kártyára): a kártya **átrepül és megnő** — a kis, bal-felső kártya a nagy, középső részletnézetbe animálódik (pozíció + méret, a layeren)
- A Console-ban: `Overlay prepared (N pairs)` + `Overlay layer: N proxy` + `Transition` (Player: OverlayTransitionPlayer)
- **Bezárás** (Bezárás gomb, kártya, vagy kattintás a háttérre): a kártya **visszazsugorodik** a kis pozícióra
- Nincs ugrás — az animáció végig sima (a proxy a from pozícióból indul)

## 4. Teszt menet

1. Másold be a 4 kód-fájlt + a 3 demó-fájlt → fordíts (hiba nélkül)
2. Play Mode → kattints a kártyára → **a kártya átrepül és megnő** (nem ugrik!)
3. Bezárás → visszazsugorodik
4. **Regresszió:** a többi demo (Dialog/BottomSheet/Popup) — a profiljukban a `useAnimationLayer` KI van → **változatlanul** működnek (a layer nem érinti őket); a tab menü / cipőcserélő (Layout) változatlan

## 5. Hogyan működik (technikailag — ADR-018)

- A layer aktív → `PrepareAnimationLayer` proxy-kat készít (a factory most a **gyermekeket is másolja** + háttérképet/szegélyt — a kártya valósághű)
- A `OverlayTransitionBuilder` a proxy-s pároknál:
  - a from/to `worldRect`-et a **layer root-hoz igazítja** (`ToLayerData`)
  - a `left/top`-ot nullázza → a freeze-elt `PositionTrack` **translate-módban** fut (a `worldRect` delta a layeren is helyes)
  - a proxyt a **from pozícióra** teszi — a translate delta arra épül
  - a slide proxykon a capture-adatokat használja (`preferCapture`)
- A **Motion Engine-hez nem nyúltunk** — csak a Builder konvertálja az adatokat

## 6. Ha valami nem működik

- **A kártya nem repül, csak ugrik** → a `useAnimationLayer` nincs TRUE a profilban (ez a layer nélkül a sima track — a kártya a helyén marad és a commit vált)
- **A kártya rossz helyre repül** → a StateCache elavult → **exportáld újra**
- **A proxy üres doboz / nem úgy néz ki** → a factory gyermek-másolása nem futott (a régi `OverlayElementFactory.cs` van fent — cseréld)
- **Nincs `Overlay layer: N proxy` log** → a `useAnimationLayer` nincs bekapcsolva, vagy a régi `OverlayRuntime.cs` van fent
- **Fordítási hiba** → a 4 kód-fájlt EGYÜTT cseréld (a szignatúrák összefüggenek: `ApplyAppearMode` preferCapture, `Build` layerRoot)
