# v0.4 — P5/2: Popup demo — telepítés és teszt

> A P5 második esete: a popup (menü) — a Dialog/Bottom Sheet mintától eltérő
> variáció: **nincs sötétítő háttér**, kattintás a háttérre zár, a menüpontok
> zárnak kiválasztáskor, a "Menü" gomb toggle. A megjelenés a meglévő
> `Fade` AppearMode-dal megy — **új engine-funkció nélkül** (bizonyítja,
> hogy a pipeline már "sablonként" működik új esetekre).

---

## 2. Beállítás (új GameObject, pl. `PopupDemo`)

1. `UIDocument` (Source Asset = NONE) + `FigmaDocumentHost` + `FigmaStateMachine` (states: [PopupMenu_Closed, PopupMenu_Open]) + `TransitionPlayer` + `OverlayRuntime` + `OverlayScene` + `OverlayTransitionPlayer` + `PopupMenuDemoInput` (machine → a StateMachine)
2. Profil: `animationMode = Overlay`
3. **TransitionAsset:** Play Mode → Next (a PopupDemo StateMachine-én) → Motion Studio → Generate → az asset a `transitionAsset` mezőre. A `MenuPanel` item **Appear = Fade** (alap — nem kell SlideUp)

## 3. Elvárt viselkedés

- **Megnyitás** ("Menü" gomb): a `MenuPanel` **fade-in** (a menüpontokkal együtt — a panel egy track, az Optimize a gyerekeket levágja)
- **Menüpont kiválasztása** (Profil / Beállítások / Kijelentkezés): a logban `[FigmaFlowDemo] OptionX kiválasztva -> bezárás`, a popup bezárul
- **Kattintás a háttérre** (a képernyőre, a menün kívül): bezárul (click-away — nincs Backdrop!)
- **"Menü" gomb toggle:** nyitva állapotban rákattintva bezárul
- **A panelen belüli kattintás** (a gombok közötti üres részre): NEM zár (barrier)
- Nincs automatikus bezárás (késleltetett GoToState + cooldown)

## 4. Teszt menet

1. Play Mode → "Menü" → `[FigmaFlowDemo] OpenMenu -> GoToState(1)` → a panel fade-in
2. Kattints egy menüpontra → bezárul (fade-out)
3. Nyisd meg újra → kattints a háttérre → bezárul
4. Nyisd meg → kattints a "Menü" gombra → bezárul (toggle)
5. Nyisd meg → kattints a panel üres részére → **nem** zárul
6. **Regresszió:** a Dialog és a Bottom Sheet demo továbbra is működik (Fade / SlideUp)

## 5. Megjegyzések

- A popup **scale-in** hatása (Figma-ban gyakori: a menü kicsit megnőve jelenik meg) egy jövőbeli `AppearMode` lehet (pl. `Scale`) — most nem kell, a Fade bizonyítja a mechanikát. Ha a múzeumi kioszk-élményhez kell, a v0.4 végén / v0.5-ben felvesszük.
- A menüpontok kiválasztása jelenleg csak log + bezárás — a valódi funkció (pl. állapotváltás, nézetváltás) a demó szintjén kívül esik; a mintát bármilyen akcióra ki lehet bővíteni.
