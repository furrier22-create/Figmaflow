# v0.4 — P2: asmdef telepítés (bemásolási útmutató)

> A három `.asmdef` fájl a workspace-ben készen áll. Csak bemásolod őket
> a Unity projekt `Assets/FigmaRuntime/` alá a megfelelő mappákba.

---

## 1. A fájlok és a célhelyek

| Fájl | Cél mappa | Mit fed le |
|---|---|---|
| `FigmaRuntime.asmdef` | `Assets/FigmaRuntime/` | Core, Runtime, Tracks, Data (+ Samples, ha nincs saját asmdef-je) |
| `FigmaRuntime.Editor.asmdef` | `Assets/FigmaRuntime/Editor/` | Editor mappa (csak Editor platform) |
| `FigmaRuntime.Experimental.asmdef` | `Assets/FigmaRuntime/Experimental/` | Experimental mappa (Overlay, StateCache) |

A mappastruktúra, ahová kerülnek:

```
Assets/FigmaRuntime/
├── FigmaRuntime.asmdef              ← ide
├── Core/          (FigmaRuntime assembly)
├── Runtime/       (FigmaRuntime assembly)
├── Tracks/        (FigmaRuntime assembly)
├── Data/          (FigmaRuntime assembly)
├── Editor/
│   ├── FigmaRuntime.Editor.asmdef   ← ide
│   └── ...cs
├── Experimental/
│   ├── FigmaRuntime.Experimental.asmdef ← ide
│   └── Overlay/, StateCache/
└── Samples/
```

## 2. Bemásolás után

1. Unity: hagyd lefutni a reimportot/fordítást (automatikus)
2. **Console:** ne legyen hiba. Ha "The type or namespace name ... does not exist" jön egy Experimental osztályra a Stable kódból, az azt jelenti, hogy valahol még van Stable→Experimental hivatkozás (ennek nem szabad lennie — F1 + F6 ezt már kivezette)
3. **Ellenőrzés (ajánlott):** kattints a `FigmaRuntime.asmdef`-re az Inspectorban → "Assembly Definition References" — **nem** tartalmazhatja a `FigmaRuntime.Experimental`-t
4. A `FigmaRuntime.Experimental.asmdef` **`autoReferenced: false`** — ez azt jelenti, hogy az `Assembly-CSharp` (a játékkódod) **nem** látja automatikusan az Experimental osztályait; csak azok a szerelvények, amelyek kifejezetten hivatkozzák. Ez a karantén legszigorúbb formája.

## 3. Várható mellékhatások

- **`#if UNITY_EDITOR` wrap-ek** az Editor mappában (`FigmaFlowWindow.cs`, `TransitionAssetGenerator.cs`, `TransitionAssetEditor.cs`) — mostantól feleslegesek, mert az Editor assembly csak Editorban fordul. **Nem hibásak, nem kell törölni** — takarítás a v0.4 későbbi fázisában.
- **`FigmaRuntime.Editor` hivatkozza a `FigmaRuntime`-ot** (szükséges: a Motion Studio a runtime osztályokat használja) — ez a megengedett irány.
- **Gyorsabb fordítás** — az Experimental külön szerelvény, a Stable változásakor nem kell újrafordulnia.

## 4. Ha bármi hibát látsz

Küldd a Console hibát — megnézzük. A leggyakoribb eset: egy fájl rossz mappában van (pl. egy Overlay fájl véletlenül a Runtime-ban maradt a másolásnál), vagy egy `using FigmaRuntime.Editor;` került runtime kódba.
